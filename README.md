# Mensuration Lab

A mobile-friendly interactive mensuration website for secondary-level maths.

## Included

- 2D shapes
- 3D solids
- Combined shapes
- Prism + pyramid
- Crystal: prism + 2 pyramids
- Double-pyramid crystal
- Live interactive diagrams
- Sliders + manual dimensions
- Volume / area / TSA / CSA / perimeter
- Formula board
- Show working
- Mini challenges
- mm / cm / m
- π / 22÷7 / 3.14
- Mobile, tablet and desktop responsive

## Upload to GitHub

Upload these files to the root of your repository:

- `index.html`
- `style.css`
- `script.js`

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch.
5. Select `/ (root)`.
6. Click **Save**.

GitHub will generate the public website URL.

No build step or backend is required.
